// what's inside

Run the whole school from one dashboard.

Courses own their session plan and instructors, groups hold students and the schedule, and every change shows up in the student app right away.
01

Courses

Each course owns its session plan and its instructors. Its groups, students and numbers in one place.

02

Session plan

Paste the course's sessions once, one per line. Line n names session n everywhere.

03

Schedule

Weekly slots become dated sessions in Cairo time, already named. Reschedule, cancel or delete any of them.

04

Add session

Pick the name from the course list, then the number, date, one of the course's instructors and a session link.

05

Students

Every student in the academy. Search by name, email or phone, filter by course, activate or add to a group.

06

Instructors

Add each instructor once and see the courses they teach. Sessions only offer the course's own instructors.

07

Arabic & English

Full right-to-left layout. English names like "C++" stay readable inside the Arabic interface.

08

Student app

Countdown and one-tap join, the full schedule, recordings, and reminders 24h and 1h before.
